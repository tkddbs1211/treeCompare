과제 05: 순차 탐색과 이진 탐색 트리(BST) 탐색 성능 비교 분석

1. 결과

100개의 임의의 정수(0~1000)를 대상으로 배열 기반 순차 탐색과 연결 구조 기반 이진 탐색 트리(BST) 탐색을 50회의 임의 키에 대해 수행한 결과는 다음과 같습니다.

- 순차 탐색 총 비교 횟수 (50회 탐색): 4504회
- 순차 탐색 평균 비교 횟수: 90.08회

- BST 탐색 총 비교 횟수 (50회 탐색): 426회
- BST 탐색 평균 비교 횟수: 8.52회

- BST 생성 비용 (비교 횟수): 683회
- BST 총 누적 비용 (생성 비용 + 탐색 비용): 1109회

2. 성능 분석 및 설명

(1) 순차 탐색 vs BST 탐색 성능 차이 분석
- 탐색 효율성
  BST 탐색의 평균 비교 횟수(8.52회)는 순차 탐색의 평균 비교 횟수(90.08회) 대비 약 10.5배 이상 빠른 성능을 보였습니다.

- 이유
  순차 탐색은 배열의 첫 원소부터 하나씩 비교하므로 탐색 대상이 존재하지 않거나 배열의 뒤쪽에 위치할 경우 전체 데이터 개수인 100개에 가깝게 비교해야 합니다. 실제로 실패한 탐색 대부분에서 100회의 비교가 발생했습니다.
  반면 BST 탐색은 노드를 이동할 때마다 탐색 범위가 약 절반씩 감소하므로, 데이터가 100개일 때 트리의 높이에 비례하는 약 7회 안팎의 적은 비교만으로 탐색 성공/실패를 판가름할 수 있습니다.


(2) BST 생성 비용을 고려한 종합 분석
- 초기 생성 비용
  BST를 구축하는 데 100개 노드 삽입 과정에서 총 683회의 비교 연산이 발생했습니다.

- 손익분기점 분석
  50회 탐색 시 순차 탐색 총비용(4504회)과 BST 총비용(생성 683회 + 탐색 426회 = 1109회)을 비교하면, 생성 비용을 포함하더라도 BST 방식이 전체 비교 횟수를 약 75.4% 절감했습니다.
  1회 탐색당 절감되는 비교 횟수는 약 81.56회이며, 이를 통해 계산해 보면 약 9회 이상의 탐색만 수행하더라도 BST 구축에 들어간 초기 비용을 모두 회수하고 전체 시스템의 성능상 이점을 얻게 됩니다. 따라서 데이터 탐색이 자주 일어나는 환경일수록 BST의 효율성이 더욱 높아집니다.


(3) BST 구조에 따른 탐색 성능 변동성 분석
- 완전/편향 트리의 영향
  본 실험에서는 정수를 임의의 순서로 삽입하여 비교적 균형 잡힌 트리가 형성되었으며, 이에 따라 평균 8.52회라는 효율적인 탐색 결과를 얻었습니다.
  만약 데이터가 이미 정렬된 순서(예: 1, 2, 3, ...)로 입력되는 최악의 경우, BST는 한쪽으로만 자식이 치우친 편향 트리 형태가 됩니다.
  편향 트리가 될 경우 트리의 높이가 데이터 개수만큼 높아져 BST 탐색 성능 및 생성 성능이 순차 탐색과 동일하게 저하될 수 있습니다.
  따라서 실제 운영 환경에서 안정적인 탐색 성능을 보장받기 위해서는 Red-Black 트리나 AVL 트리와 같은 균형 이진 탐색 트리 구조의 도입이 필요합니다.
